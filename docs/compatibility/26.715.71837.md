# Codex Desktop 26.715.71837 compatibility

Status: **NSPanel companion host implemented; live Quick Chat verification pending**

Validated on 2026-07-22:

- Codex Desktop: `26.715.71837`
- Bundled CLI: `codex-cli 0.145.0-alpha.30`
- Chromium: `150.0.7871.124`
- CDP is restricted to a random `127.0.0.1` port.
- `command/exec`, output streaming, termination, `workspaceWrite`, and network denial pass the real App Server integration test.

Window decision:

- The native avatar overlay is created with `resizable: false`.
- `Browser.getWindowForTarget` cannot obtain its native browser window.
- AX reports its size as non-settable.
- The IDE therefore uses a controller-owned `NSPanel + WKWebView`; no Accessibility permission is required.

Renderer compatibility profile:

- Main `app://` target validation.
- `Files` Sidepanel row discovery and entry reinjection.
- Current Codex composer discovery.
- Quick Chat activation by `⌘⌥N`, followed by a version-bound visible-control signal fallback.
- Strict Quick Chat marker checks prevent accidentally writing More details into a Codex composer.

The controller does not modify Codex files, ASAR, signature, or private IPC.
